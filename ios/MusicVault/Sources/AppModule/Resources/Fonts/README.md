# Font files

Place the following font files in this directory:

- SpaceGrotesk-VariableFont_wght.ttf (Space Grotesk variable font, 400-700)
- Inter-VariableFont_opsz,wght.ttf (Inter variable font)
- IBMPlexMono-VariableFont_wght.ttf (IBM Plex Mono variable font)

Download from:
- Space Grotesk: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- Inter: https://github.com/google/fonts/tree/main/ofl/inter
- IBM Plex Mono: https://github.com/IBM/plex/tree/master/fonts/IBM-Plex-Mono

After adding the font files, they will be automatically included in the app bundle via the Resources folder in Package.swift.
