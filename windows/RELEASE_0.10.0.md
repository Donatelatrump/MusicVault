MusicVault 0.10.0 para Windows x64 incluye:

- Revisión automática de actualizaciones en GitHub y comprobación manual en Ajustes.
- JAMS con salas visuales, invitaciones, amigos, identidad anónima y cola compartida.
- Perfiles de artista con canciones, búsqueda, álbumes y sus pistas.
- Más de 2,200 géneros y artistas paginados con fotografías.
- Corrección de carátulas, Favoritos por streaming, corazón relleno y controles circulares.
- DJ para ti en Inicio, separado de JAMS / Amigos.

El instalador y el portable incluyen las dependencias: Python, Qt/WebEngine,
libmpv, FFmpeg, yt-dlp, Node, Firebase y NewPipeExtractor con Java privado.
No necesitas instalarlas por separado.

Para actualizar una instalación existente, ciérrala y elige su misma carpeta.
La biblioteca y preferencias en Data se conservan.
